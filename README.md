# Physical Computing

This is your GitHub repository for Physical Computing.

You may delete this `README` file and replace it with your own introduction to your portfolio.

Only files pushed to your repository before the assessment deadline will be marked. Ensure you give yourself enough time before your final push.

## Experiments Portfolio

Your task is to create a portfolio of physical computing experiments, leading to the creation and presentation of a 'final' personal project of your own choosing. The project can be of practical use, or purely artistic. It does not have to be a polished product, or even fully successful, provided there is an interesting sequence of technical investigations leading up to it.

*Please read the full assessment brief on Ultra.*

You should create a folder for each entry in your portfolio. The folder should contain a Markdown file named `README.md`, as well as any videos, photos, code, or other files relevant to the experiment.

You can read more about [how to write Markdown files](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax) using this guide.

> Tip: When you open a `README.md` file in Visual Studio Code, you can view it in a nice format using the `Markdown: Open Preview command`, or `Ctrl+Shift+V`.
> 
> This works for any Markdown file, which is any file that has the `.md` extension.
