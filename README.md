# Physical Computing Portfolio

This repository contains my experiments and final project for the Physical Computing module. The purpose of this portfolio is to document my learning process, from initial experiments to a complete project.

## 📂 Folder Structure
- `experiments/` – Contains my experiments with Arduino and physical computing components.
- `final-project/` – Contains the final project, including its concept, code, and media.

## 🚀 Getting Started
Each experiment and project entry has a `README.md` with descriptions, code and media.
